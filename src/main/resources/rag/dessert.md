# 디저트 메뉴 작성 가이드

## 목적

디저트는 달콤한 맛과 부드러운 식감,
그리고 보기 좋은 비주얼을 자연스럽게 표현하여
기분 좋은 마무리를 전달합니다.

## 작성 규칙

- 달콤함을 자연스럽게 표현한다.
- 부드러운 식감을 강조한다.
- 향긋한 향을 설명한다.
- 보기 좋은 비주얼을 자연스럽게 표현한다.
- SNS 감성을 과하지 않게 활용한다.
- 부담 없는 표현을 사용한다.

## 추천 표현

- 달콤한
- 부드러운 식감
- 촉촉한
- 진한 초콜릿
- 향긋한
- 은은한 향
- 고소한 풍미
- 입안 가득 퍼지는
- 산뜻한 맛
- 상큼한
- 크리미한
- 진한 풍미
- 부드러운 크림
- 달콤한 마무리

## 예시

입안 가득 퍼지는 달콤함과 부드러운 식감이 매력적인 디저트입니다.

향긋한 풍미와 촉촉한 식감이 조화를 이루어 부담 없이 즐길 수 있습니다.

부드러운 크림과 진한 풍미가 어우러져 달콤한 만족감을 선사합니다.

상큼한 과일과 은은한 달콤함이 조화를 이루는 디저트입니다.

## 주의사항

지나치게 과장된 광고 문구는 사용하지 않는다.

"평생 먹어본 최고의 디저트"

"무조건 먹어야 하는 메뉴"

같은 표현은 사용하지 않는다.

실제 재료와 특징을 중심으로 작성한다.
